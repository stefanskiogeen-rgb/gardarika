# SQL-скрипты базы данных «Гардарика»

| Файл | Назначение |
| --- | --- |
| [schema.sql](schema.sql) | Полный скрипт создания структуры базы данных: таблицы, представления, хранимые процедуры/функции, триггеры и заполнение справочников начальными значениями |

## Применение

```bash
# Из контейнера или с установленным psql:
psql -U gardarika -d gardarika_db -f sql/schema.sql
```

При первичном развёртывании через `docker compose up`, схема автоматически
создаётся приложением Flask (через `db.create_all()`); скрипт `schema.sql`
полезен для:

- ручного развёртывания / восстановления базы;
- демонстрации структуры данных в курсовом проекте (Приложение В);
- создания представлений, процедур, функций и триггеров,
  которые не описаны в SQLAlchemy-моделях.

## Структура базы данных

Таблицы:

- `roles` — справочник ролей пользователей;
- `users` — учётные записи пользователей;
- `specializations` — специализации тренеров;
- `trainers` — тренеры;
- `breeds` — породы лошадей;
- `horses` — лошади клуба;
- `riders` — наездники (клиенты);
- `services` — услуги клуба;
- `workouts` — тренировки;
- `workout_participants` — участники тренировок.

Представления:

- `v_workouts_full` — расширенные данные о тренировках;
- `v_riders_balance` — остатки абонементов и статистика по наездникам.

Функции и процедуры:

- `fn_decrement_subscription(rider_id)` — списание занятия абонемента;
- `sp_close_workout(workout_id)` — закрытие тренировки;
- `fn_revenue_for_period(d_from, d_to)` — выручка за период.

Триггеры:

- `trg_workout_overlap` — запрет пересечения тренировок одного тренера;
- `trg_users_username_lower` — приведение логина к нижнему регистру.
