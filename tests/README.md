# Тесты приложения «Гардарика»

Набор `pytest`-тестов для проверки ключевой функциональности
информационной системы конноспортивного клуба.

## Запуск

```bash
pip install -r requirements.txt
pip install pytest
pytest tests/ -v
```

Тесты используют временную SQLite-базу (создаётся автоматически
во временном каталоге), чтобы не трогать рабочую базу PostgreSQL.

## Состав тестов

| Файл | Что проверяет |
| --- | --- |
| `test_auth.py` | Хеширование паролей, маршруты `/login` и `/dashboard`, поведение при анонимном/успешном/неуспешном входе |
| `test_models.py` | Создание основных моделей предметной области (Role, User, Horse, Rider, Service, Workout) |
