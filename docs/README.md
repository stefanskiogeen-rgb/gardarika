# Документация курсового проекта «Гардарика»

Каталог содержит полный комплект документации к курсовому проекту по
дисциплине **МДК.11.01 Технология разработки и защиты баз данных**
специальности **09.02.07 Информационные системы и программирование**.

| Файл | Назначение |
| --- | --- |
| [Аннотация.docx](Аннотация.docx) | Краткая аннотация курсового проекта |
| [План-график.docx](План-график.docx) | План-график выполнения курсового проекта |
| [Ведомость_курсового_проекта.docx](Ведомость_курсового_проекта.docx) | Ведомость курсового проекта (форма по ГОСТ) |
| [Задание_на_разработку.docx](Задание_на_разработку.docx) | Задание на разработку (электронная версия) |
| [Пояснительная_записка.docx](Пояснительная_записка.docx) | Полная пояснительная записка курсового проекта |

Все документы оформлены по требованиям ГОСТ:
- шрифт **Times New Roman**, кегль **14 пт**;
- междустрочный интервал **1,5**;
- абзацный отступ **1,25 см**, выравнивание по ширине;
- поля: левое **30 мм**, правое **15 мм**, верхнее/нижнее **20 мм**;
- формат страницы **А4** (210 × 297 мм).
